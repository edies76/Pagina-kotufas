# Página Kotufas

Breve descripción
-----------------
Página web estática dedicada a las "kotufas" (palomitas de maíz). Es un sitio informativo y visual que reúne recetas, historia, secciones temáticas, recursos multimedia y pequeñas interacciones para quien quiera conocer más sobre este snack.

Qué es (no cómo ejecutarlo)
---------------------------
- Es un sitio web estático (HTML/CSS/JS) pensado para presentar contenido: recetas, curiosidades, galerías y secciones de progreso o desarrollo del proyecto.
- No es una aplicación de backend, no proporciona autenticación ni persistencia remota.
- No es un servicio en producción ni una API; su propósito principal es informativo y de demostración educativa.

Estructura principal del repositorio
-----------------------------------
- Páginas HTML destacadas:
  - `Index.html` — Página principal / índice.
  - `NuestroProyecto.html` — Sección principal del proyecto.
  - `Kotufas NuestroProyecto.html` — Variante/sección del proyecto.
  - `KotufasProgreso.html` — Página que documenta el progreso o funcionalidades en desarrollo.
- Hojas de estilo (CSS):
  - `kotufas.css`, `NuestroProyecto.css`, `Kotufas NuestroProyecto.css`, `KotufasProgreso.css` — estilos para las distintas páginas.
- Scripts (JavaScript):
  - `kotufas.js`, `NuestroProyecto.js`, `KotufasProgreso.js`, `kotufasNuestroProyecto.js` — scripts para interactividad y pequeñas funcionalidades.
- Recursos:
  - `imagenrepositorio.jpg` — imagen principal usada en el repositorio/sitio.

Tecnologías
-----------
- HTML, CSS y JavaScript (frontend estático).
- Enfoque en contenido visual y diseño para presentación.
